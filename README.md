# 动物繁殖系统模组 (Breeding)

为 Survivalcraft 2 (2.4.0.0) 加入动物繁殖系统的独立模组。

当前版本为**简化测试版**，仅对**灰狼 (Wolf_Gray)** 生效，机制已精简到最简单：冬季发情 → 异性相遇交配 → 孕期倒计时 → 分娩幼崽 → 成长变大。

---

## 一、玩法总览

灰狼会在**冬季**进入发情期。当一只发情的成年母狼附近（12 格内）存在发情的成年公狼时，两只狼会自动交配，母狼进入孕期。约 30 秒（现实秒）后母狼分娩，在身边生成一只幼狼。幼狼经过 3 个游戏天的成长后进阶为成年狼，期间体型会从最初的一半逐步长大到成年尺寸。

### 核心循环

```
冬季(发情) → 公母相遇 → 交配 → 孕期30秒 → 分娩幼崽 → 成长3天 → 成年
                                                          ↑
                                                     (成年后可再次繁殖)
```

---

## 二、繁殖机制详解

### 1. 发情期 (Estrus)

- **触发季节**：冬季 (Winter)，由配置文件 `BreedingSeasons` 决定。
- **判定方式**：每帧检查当前游戏季节是否在该物种的繁殖季节列表内。是 → `发情中`，否 → `未在季`。
- **发情效果**：
  - 母狼发情 + 附近有发情公狼 → 触发交配。
  - 发情期间仇恨范围 ×2（会更主动追击玩家/目标）。

### 2. 交配条件

需**同时满足**以下全部条件，交配才会发生：

| 条件 | 说明 |
|------|------|
| 母狼处于发情期 | 当前季节为冬季 |
| 母狼为成年 | 自然生成的狼默认成年 |
| 母狼未怀孕 | 孕期倒计时期间不会再次交配 |
| 附近有成年公狼 | 半径 12 格内（`MateRadius`） |
| 公狼同模板 | 必须同为 `Wolf_Gray` |
| 公狼处于发情期 | 公狼也需在冬季发情 |

交配成功后，母狼进入孕期，公狼记录为胎儿父亲。

### 3. 孕期与分娩

- **孕期时长**：30 秒（现实秒，测试用，可配置 `GestationSeconds`）。
- **倒计时**：每帧用真实时间 `dt` 递减 `PregnancyRemainingSeconds`。
- **孕期行为**：怀孕期间母狼不会再次交配。
- **分娩**：倒计时归零时，在母狼附近 1.5 格范围内生成 1 只幼狼。
- **幼狼模板**：使用母狼模板生成（保证外观一致），性别随机（50% 公 / 50% 母）。
- **分娩后**：母狼孕期状态重置，可立即再次交配（只要仍在发情期）。

### 4. 幼崽成长

- **幼崽期时长**：3 个游戏天（`CubDurationDays`，按 `SubsystemTimeOfDay.Day` 计算）。
- **成长进度**：0 → 1 线性增长。
  - `成长进度 = (当前天数 - 出生天数) / 幼崽期天数`，限制在 0~1。
  - 成年后恒为 1。
- **进阶成年**：年龄达到 3 天时，幼崽期 → 成年期，立即应用成年体型。

### 5. 体型动态变化

体型（碰撞盒 BoxSize）随成长进度线性插值，公式为：

```
scale = CubBoxScale + (成年scale - CubBoxScale) × 成长进度
```

| 阶段 | 公狼 | 母狼 |
|------|------|------|
| 出生（进度 0） | 0.5× | 0.5× |
| 成年（进度 1） | 1.1× | 1.0× |

- 出生时所有幼狼都是 0.5× 原版尺寸。
- 成长过程中，公狼体型增长到 1.1×（比原版大），母狼增长到 1.0×（与原版一致）。
- 体型更新做了节流处理（每 60 帧刷新一次），避免每帧写入碰撞盒造成性能开销。

### 6. 攻击力差异

攻击力按成长阶段和性别双重乘算：

```
最终攻击力 = 基础攻击力 × 阶段系数 × 性别系数
```

| 阶段 | 阶段系数 | 性别 | 性别系数 |
|------|---------|------|---------|
| 幼崽 | ×0.3 | 公 | ×1.3 |
| 成年 | ×1.0 | 母 | ×1.0 |

**示例**：
- 成年公狼：基础 × 1.0 × 1.3 = **1.3×**（最强）
- 成年母狼：基础 × 1.0 × 1.0 = **1.0×**
- 幼狼（无论性别）：基础 × 0.3 × (1.0 或 1.3) = **0.3× 或 0.39×**（最弱）

### 7. 发情期仇恨范围

发情期间，狼的仇恨追击范围会乘以 `EstrusChaseRangeMultiplier`（默认 ×2）。这意味着冬季发情的狼会从更远的地方发现并追击玩家，需格外小心。

## 三、头顶浮动文字

每只被繁殖系统追踪的狼头顶会显示 3 行浮动文字，便于玩家观察状态：

```
♂公 灰狼              ← 第1行：性别 + 生物名
成年期 | 发情中        ← 第2行：成长阶段 + 繁殖状态
成长 100% [██████]    ← 第3行：成长进度 + 进度条
```

### 各字段含义

**第 1 行 — 性别 + 名称**
- `♂公` / `♀母` + 生物显示名（如「灰狼」）

**第 2 行 — 成长阶段 + 繁殖状态**

| 成长阶段 | 繁殖状态 | 含义 |
|---------|---------|------|
| 幼崽期 | 成长中 | 幼狼正在成长，未到发情季节 |
| 幼崽期 | 发情中 | 幼狼在冬季（但幼崽不会交配） |
| 成年期 | 发情中 | 成年且在冬季，可交配 |
| 成年期 | 怀孕中(N秒) | 母狼怀孕，N 为剩余秒数 |
| 成年期 | 未在季 | 成年但不在繁殖季节 |

**第 3 行 — 成长进度**
- 百分比 + 6 格 ASCII 进度条：`成长 60% [███░░░]`
- 成年后固定显示 `成长 100% [██████]`

> 浮动文字在 16 格内全显，19 格外淡出隐藏；狼死亡后（尸体状态）不再显示。

## 四、配置文件

所有参数在 [MOD/Assets/BreedingConfig.json](MOD/Assets/BreedingConfig.json)，**退出世界重进即生效**，无需重新编译。

### 全局参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `Enabled` | `true` | 全局开关，关闭后繁殖系统完全不生效 |
| `GestationSeconds` | `30.0` | 孕期持续秒数（现实秒）。母狼交配后此秒数分娩 |
| `EstrusChaseRangeMultiplier` | `2.0` | 发情期仇恨范围倍率（乘到 ChaseRange 上） |
| `CubAttackFactor` | `0.3` | 幼崽攻击力系数 |
| `AdultAttackFactor` | `1.0` | 成年攻击力系数 |
| `MaleAttackBonus` | `1.3` | 公狼攻击力额外倍率（母狼为 1.0） |
| `CubBoxScale` | `0.5` | 幼崽出生时体型缩放（相对原版） |
| `AdultMaleBoxScale` | `1.1` | 成年公狼体型缩放 |
| `AdultFemaleBoxScale` | `1.0` | 成年母狼体型缩放 |
| `MateRadius` | `12.0` | 寻找交配对象的半径（方块） |

### 物种配置 (`Species`)

按实体模板名索引，当前仅配置灰狼：

```json
"Species": {
  "Wolf_Gray": {
    "BreedingSeasons": [ "Winter" ],
    "CubDurationDays": 3
  }
}
```

| 参数 | 说明 |
|------|------|
| `BreedingSeasons` | 繁殖季节，可选值：`Summer` / `Autumn` / `Winter` / `Spring` |
| `CubDurationDays` | 幼崽期持续天数（游戏天），到期进阶成年 |

> 要添加新物种繁殖，在 `Species` 下添加对应模板名条目即可，代码无需改动。

## 五、测试步骤

1. **进入世界**：创造模式进入世界，确保季节变化开启。
2. **调整季节**：将季节调至**冬季**（发情期）。
3. **刷狼**：用刷怪蛋刷 4~6 只灰狼（`Wolf_Gray`）在围栏内，确保公母都有。
4. **观察交配**：约几秒内，查看日志应出现 `[Breeding] 交配成功`，母狼头顶显示`怀孕中(30秒)`。
5. **等待分娩**：30 秒后母狼身边生成幼狼，日志出现 `[Breeding] 分娩成功`。
6. **观察成长**：幼狼头顶显示`幼崽期 | 成长中`和成长进度条，体型随天数逐渐变大。
7. **进阶成年**：3 个游戏天后，幼狼头顶变为`成年期`，体型到达成年尺寸（公大母小）。
8. **循环繁殖**：成年后若仍在冬季，可继续与发情异性交配，形成繁殖循环。

### 日志关键字

| 日志 | 含义 |
|------|------|
| `[Breeding] OnEntityAdd 注册新个体` | 狼被系统追踪 |
| `[Breeding] 交配成功` | 公母狼完成交配，母狼进入孕期 |
| `[Breeding] 分娩成功` | 母狼产下幼狼 |
| `[Breeding] 幼崽进阶成年` | 幼狼成长完毕，变为成年 |

## 六、安装

1. 用 Visual Studio / Rider 打开 `BreedingMod.csproj`
2. 把游戏目录下的 `Engine.dll` / `EntitySystem.dll` / `Survivalcraft.dll` 复制到 `Quoted/` 目录
3. 编译生成 `BreedingMod.dll`，放入 `MOD/` 目录
4. 把 `MOD/` 目录打包为 `.pak` 文件
5. 放到游戏的 `Mods/` 目录

## 七、技术说明

### 文件结构

| 文件 | 职责 |
|------|------|
| [BreedingModLoader.cs](BreedingModLoader.cs) | 模组入口，注册 Hook 并处理浮动文字渲染 |
| [Breeding/SubsystemBreeding.cs](Breeding/SubsystemBreeding.cs) | 繁殖系统核心：发情判定、交配、孕期、分娩、成长、体型、攻击力 |
| [Breeding/BreedingState.cs](Breeding/BreedingState.cs) | 单只动物的运行时状态（性别/阶段/孕期），含 JSON 序列化 |
| [Breeding/BreedingConfig.cs](Breeding/BreedingConfig.cs) | 配置文件加载与缓存 |
| [MOD/Assets/BreedingConfig.json](MOD/Assets/BreedingConfig.json) | 外部配置文件 |

### 运行时数据流

```
OnEntityAdd          → 注册新个体(成年/随机性别) → 缓存原版BoxSize → 应用体型
OnFactorsUpdate(每帧) → 发情判定 → 成长推进 → 体型更新 → ChaseRange → 母体孕期/交配
OnMinerHit           → 攻击力修正(阶段×性别)
OnSaveSpawnData      → 状态序列化为 JSON 存档
OnReadSpawnData      → 读档恢复状态
OnModelRendererDrawExtra → 头顶浮动文字渲染
```

### 状态持久化

繁殖状态通过 `SpawnEntityData.Data`（JSON 字符串）随实体存档保存/读取。`OriginalBoxSize` 和 `IsInEstrus` 标记为 `[JsonIgnore]`，前者在加载时重新缓存，后者每帧重新计算。

### 体型更新节流

为避免每帧写入所有狼的碰撞盒，幼崽体型每 60 帧全局更新一次。由于成长周期为 3 游戏天，这种节流对视觉效果无可感知影响。
