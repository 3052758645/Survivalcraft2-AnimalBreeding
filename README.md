# 动物繁殖系统模组 (Breeding)

为 Survivalcraft 2 (2.4.0.0) 加入动物繁殖系统的独立模组。

当前版本为**简化测试版**，仅对**灰狼 (Wolf_Gray)** 生效。公狼会主动寻找母狼，相处 10 秒后交配，双方进入虚弱期，母狼怀孕 30 秒后分娩，幼崽 3 天成长成年。

---

## 一、玩法总览

灰狼在**冬季**进入发情期。发情的公狼会**主动寻找**附近的发情母狼并走过去。当公母狼在 2 格内**持续相处 10 秒**后触发交配，母狼进入孕期，双方进入虚弱期（不再发情）。约 30 秒后母狼分娩产下幼狼，母狼再次进入虚弱期。幼狼经 3 个游戏天成长后进阶成年，体型从最初的一半逐步长大到成年尺寸（公狼比母狼更大）。

### 核心循环

```
冬季(发情) → 公狼寻路走向母狼 → 相处10秒 → 交配
                                            ↓
                              母狼怀孕30秒 ← 双方虚弱60秒(不发情)
                                    ↓
                              分娩幼崽 → 母狼虚弱60秒(不发情)
                                    ↓
                              幼崽成长3天 → 成年(可再次繁殖)
```

---

## 二、繁殖机制详解

### 1. 发情期 (Estrus)

- **触发季节**：冬季 (Winter)，由配置文件 `BreedingSeasons` 决定。
- **判定条件**：当前季节在繁殖季节列表内 **且** 不在虚弱期 → `发情中`。
- **发情效果**：
  - 公狼发情 → 主动寻找母狼（寻路走向她）。
  - 母狼发情 → 等待公狼靠近，相处计时。
  - 发情期间仇恨范围 ×2（更主动追击玩家/目标）。
- **虚弱期**：交配或分娩后进入，持续 60 秒。虚弱期间**不处于发情**，不会交配或寻路。

### 2. 公狼寻路

发情的成年公狼（非虚弱）会每帧执行以下逻辑：
1. 在 `SeekRadius`（20 格）内搜索最近的**发情、成年、未怀孕**母狼。
2. 找到后，通过 `ComponentPathfinding.SetDestination` 设路径走向母狼。
3. 公狼会持续走向母狼，直到进入 `MateRadius`（2 格）内。

> 若公狼正在追击玩家（ComponentChaseBehavior 激活），追击行为优先，寻路暂时中断。

### 3. 交配条件

需**同时满足**以下全部条件，交配才会发生：

| 条件 | 说明 |
|------|------|
| 母狼处于发情期 | 冬季 且 非虚弱 |
| 母狼为成年 | 自然生成的狼默认成年 |
| 母狼未怀孕 | 孕期倒计时期间不会再次交配 |
| 附近有成年公狼 | 半径 2 格内（`MateRadius`） |
| 公狼同模板 | 必须同为 `Wolf_Gray` |
| 公狼处于发情期 | 公狼也需在冬季且非虚弱 |
| **持续相处 10 秒** | 公母在 2 格内连续相处 `MatingRequiredProximitySeconds` 秒 |

> 若公狼离开 2 格范围，相处计时归零，下次需重新累计。

交配成功后：
- 母狼进入孕期（`PregnancyRemainingSeconds = GestationSeconds`）。
- **双方进入虚弱期**（`WeaknessRemainingSeconds = WeaknessSeconds`），虚弱期间不发情。
- 相处计时归零。

### 4. 孕期与分娩

- **孕期时长**：30 秒（现实秒，可配置 `GestationSeconds`）。
- **倒计时**：每帧用真实时间 `dt` 递减。
- **孕期行为**：怀孕母狼不产生仇恨（ChaseRange=0），不会再次交配。
- **分娩**：倒计时归零时，在母狼附近 1.5 格范围内生成 1 只幼狼。
- **幼狼模板**：使用母狼模板生成（保证外观一致），性别随机（50% 公 / 50% 母）。
- **分娩后**：母狼进入虚弱期（`WeaknessSeconds`），虚弱期间不发情。

### 5. 虚弱期

虚弱期是交配/分娩后的恢复阶段：

| 触发事件 | 谁进入虚弱 | 持续时间 |
|--------------------|-----------|---------|
| 交配成功 | 公狼 + 母狼 | 60 秒 |
| 分娩完成 | 母狼 | 60 秒 |

虚弱期效果：
- **不处于发情**：即使仍在冬季，也不会交配或寻路。
- **虚弱期结束**后，若仍在繁殖季节，自动恢复发情状态。

### 6. 幼崽成长

- **幼崽期时长**：3 个游戏天（`CubDurationDays`，按 `SubsystemTimeOfDay.Day` 计算）。
- **成长进度**：0 → 1 线性增长。
  - `成长进度 = (当前天数 - 出生天数) / 幼崽期天数`，限制在 0~1。
  - 成年后恒为 1。
- **进阶成年**：年龄达到 3 天时，幼崽期 → 成年期，立即应用成年体型。
- **幼崽仇恨**：幼崽不产生仇恨（ChaseRange=0），不会攻击玩家。

### 7. 体型动态变化

体型同时调整**碰撞盒 (BoxSize)** 和**视觉模型 (ModelScale)**，随成长进度线性插值：

```
scale = CubBoxScale + (成年scale - CubBoxScale) × 成长进度
```

| 阶段 | 公狼 | 母狼 |
|------|------|------|
| 出生（进度 0） | 0.5× | 0.5× |
| 成年（进度 1） | 1.3× | 1.0× |

- 出生时所有幼狼都是 0.5× 原版尺寸。
- 成长过程中，公狼体型增长到 1.3×（比原版大 30%），母狼增长到 1.0×（与原版一致）。
- 体型更新做了节流处理（每 60 帧刷新一次），避免每帧写入造成性能开销。

### 8. 攻击力差异

攻击力按成长阶段和性别双重乘算：

```
最终攻击力 = 基础攻击力 × 阶段系数 × 性别系数
```

| 阶段 | 阶段系数 | 性别 | 性别系数 |
|------|---------|------|---------|
| 幼崽 | ×0.3 | 公 | ×1.3 |
| 成年 | ×1.0 | 母 | ×1.0 |

**示例**：
- 成年公狼：基础 × 1.0 × 1.3 = **1.3×**（最强）
- 成年母狼：基础 × 1.0 × 1.0 = **1.0×**
- 幼狼（无论性别）：基础 × 0.3 × (1.0 或 1.3) = **0.3× 或 0.39×**（最弱）

### 9. 仇恨机制

| 状态 | 仇恨行为 |
|------|---------|
| 幼崽（公/母） | **不产生仇恨**（ChaseRange=0，不会追击玩家） |
| 怀孕母狼 | **不产生仇恨**（ChaseRange=0） |
| 成年公狼 | 正常攻击玩家；发情期仇恨范围 ×2 |
| 成年母狼（非怀孕） | 正常攻击；发情期仇恨范围 ×2 |
| 虚弱期 | 无额外效果（仇恨正常，但不发情） |

## 三、头顶浮动文字

每只被繁殖系统追踪的狼头顶会显示 3 行浮动文字：

```
♂公 灰狼                    ← 第1行：性别 + 生物名
成年期 | 发情中               ← 第2行：成长阶段 + 繁殖状态
成长 100% [██████]          ← 第3行：成长进度 + 进度条
```

### 第 2 行 — 繁殖状态详解

| 繁殖状态 | 含义 |
|---------|------|
| `成长中` | 幼崽正在成长，未到发情季节 |
| `发情中` | 成年且在冬季，可交配 |
| `发情中(相处N秒)` | 母狼附近有公狼，正在累计相处时间（N/10 秒） |
| `怀孕中(N秒)` | 母狼怀孕中，N 为剩余秒数 |
| `虚弱中(N秒)` | 交配/分娩后恢复中，N 为剩余秒数，期间不发情 |
| `未在季` | 成年但不在繁殖季节 |

> 浮动文字在 16 格内全显，19 格外淡出隐藏；狼死亡后（尸体状态）不再显示。

## 四、配置文件

所有参数在 [MOD/Assets/BreedingConfig.json](MOD/Assets/BreedingConfig.json)，**退出世界重进即生效**，无需重新编译。

### 全局参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `Enabled` | `true` | 全局开关 |
| `GestationSeconds` | `30.0` | 孕期持续秒数（现实秒） |
| `EstrusChaseRangeMultiplier` | `2.0` | 发情期仇恨范围倍率 |
| `CubAttackFactor` | `0.3` | 幼崽攻击力系数 |
| `AdultAttackFactor` | `1.0` | 成年攻击力系数 |
| `MaleAttackBonus` | `1.3` | 公狼攻击力额外倍率 |
| `CubBoxScale` | `0.5` | 幼崽出生时体型缩放 |
| `AdultMaleBoxScale` | `1.3` | 成年公狼体型缩放 |
| `AdultFemaleBoxScale` | `1.0` | 成年母狼体型缩放 |
| `MateRadius` | `2.0` | 交配判定半径（方块） |
| `SeekRadius` | `20.0` | 公狼寻找母狼的搜索半径（方块） |
| `MatingRequiredProximitySeconds` | `10.0` | 交配所需相处时间（现实秒） |
| `WeaknessSeconds` | `60.0` | 虚弱期持续秒数（现实秒） |

### 物种配置 (`Species`)

```json
"Species": {
  "Wolf_Gray": {
    "BreedingSeasons": [ "Winter" ],
    "CubDurationDays": 3
  }
}
```

| 参数 | 说明 |
|------|------|
| `BreedingSeasons` | 繁殖季节：`Summer` / `Autumn` / `Winter` / `Spring` |
| `CubDurationDays` | 幼崽期天数（游戏天），到期进阶成年 |

> 添加新物种只需在 `Species` 下添加对应模板名条目，代码无需改动。

## 五、测试步骤

1. **进入世界**：创造模式，确保季节变化开启。
2. **调至冬季**：将季节调至冬季（发情期）。
3. **刷狼**：用刷怪蛋刷 4~6 只灰狼（`Wolf_Gray`），确保公母都有。
4. **观察寻路**：公狼头顶显示`发情中`，会主动走向母狼。
5. **观察相处**：公母狼在 2 格内时，母狼头顶显示`发情中(相处N秒)`，N 逐步增加。
6. **交配**：相处达 10 秒后，日志出现 `[Breeding] 交配成功`，双方头顶变为`虚弱中(60秒)`，母狼同时显示`怀孕中(30秒)`。
7. **分娩**：30 秒后母狼身边生成幼狼，日志出现 `[Breeding] 分娩成功`，母狼头顶变为`虚弱中(60秒)`。
8. **成长**：幼狼头顶显示`幼崽期 | 成长中`和进度条，**体型随天数逐渐变大**。
9. **成年**：3 个游戏天后，幼狼头顶变为`成年期`，体型到达成年尺寸（公 1.3× 大，母 1.0×）。
10. **循环**：虚弱期结束后，若仍在冬季，可再次交配繁殖。

### 日志关键字

| 日志 | 含义 |
|------|------|
| `[Breeding] OnEntityAdd 注册新个体` | 狼被系统追踪 |
| `[Breeding] 交配成功(相处10秒)` | 公母狼相处达标，完成交配 |
| `[Breeding] 分娩成功` | 母狼产下幼狼 |
| `[Breeding] 幼崽进阶成年` | 幼狼成长完毕 |
| `[Breeding] 虚弱期结束` | 虚弱期结束，可恢复发情 |

## 六、安装

1. 用 Visual Studio / Rider 打开 `BreedingMod.csproj`
2. 把游戏目录下的 `Engine.dll` / `EntitySystem.dll` / `Survivalcraft.dll` 复制到 `Quoted/` 目录
3. 编译生成 `BreedingMod.dll`，放入 `MOD/` 目录
4. 把 `MOD/` 目录打包为 `.pak` 文件
5. 放到游戏的 `Mods/` 目录

## 七、技术说明

### 文件结构

| 文件 | 职责 |
|------|------|
| [BreedingModLoader.cs](BreedingModLoader.cs) | 模组入口，注册 Hook 并处理浮动文字渲染 |
| [Breeding/SubsystemBreeding.cs](Breeding/SubsystemBreeding.cs) | 繁殖系统核心：发情/寻路/相处/交配/孕期/分娩/成长/体型/攻击力/仇恨 |
| [Breeding/BreedingState.cs](Breeding/BreedingState.cs) | 单只动物的运行时状态（性别/阶段/孕期/虚弱/相处计时），含 JSON 序列化 |
| [Breeding/BreedingConfig.cs](Breeding/BreedingConfig.cs) | 配置文件加载与缓存 |
| [MOD/Assets/BreedingConfig.json](MOD/Assets/BreedingConfig.json) | 外部配置文件 |

### 运行时数据流

```
OnEntityAdd          → 注册新个体(成年/随机性别) → 缓存原版BoxSize+ModelScale → 应用体型
OnFactorsUpdate(每帧) → 虚弱倒计时 → 发情判定 → 成长推进 → 体型更新 → 仇恨Factor → 性别更新
                       母狼: 孕期倒计时/相处交配
                       公狼: 寻路走向母狼
OnMinerHit           → 攻击力修正(阶段×性别)
OnSaveSpawnData      → 状态序列化为 JSON 存档
OnReadSpawnData      → 读档恢复状态
OnModelRendererDrawExtra → 头顶浮动文字渲染
```

### 关键设计决策

- **体型修复**：同时设置 `ComponentBody.BoxSize`（碰撞盒）和 `ComponentModel.ModelScale`（视觉模型），确保幼崽体型在视觉和物理上同步变化。
- **公狼寻路**：通过 `ComponentPathfinding.SetDestination` 设路径走向母狼。若追击行为（ComponentChaseBehavior）激活则追击优先。
- **相处计时**：放在母狼侧。每帧检查 MateRadius 内有无发情公狼，有则累加，无则归零。达阈值后触发交配。
- **虚弱期**：交配/分娩后设 `WeaknessRemainingSeconds`，虚弱期间 `IsInEstrus=false`，阻止交配和寻路。
- **仇恨控制**：通过 `ComponentFactors.OtherFactors["ChaseRange"]` 添加 factor。值为 0 且 Multiply 类型 → 仇恨范围归零。
- **状态持久化**：通过 `SpawnEntityData.Data`（JSON）随实体存档。`OriginalBoxSize`/`OriginalModelScale`/`IsInEstrus`/`IsWeak` 标记 `[JsonIgnore]`，加载时重新缓存或每帧重算。
